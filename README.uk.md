# Textile Expert (коротко українською)

`textile-expert` — навичка (Agent Skill) для інтернет-магазину текстилю в Україні, який імпортує з Туреччини, Італії, Китаю, Німеччини та Португалії. Вона працює як технолог і комерційний директор в одній особі: тканини, волокна та щільність, вибір і перевірка постачальників, повна собівартість і ціна, контроль якості та сертифікати, картки товарів і SEO українською, маркування, повернення, правила ввезення.

Повний опис англійською — у [README.md](README.md).

## Встановлення в Claude Code

```bash
claude plugin marketplace add dmitriy990/textile-expert-skills
```

```bash
claude plugin install textile-expert@ivatech-textile
```

Далі просто формулюйте завдання: «склади картку товару», «порахуй собівартість і ціну», «перевір цей прайс». Потрібен `python3` у PATH. Інші способи (ручне копіювання, Claude.ai) описані в [README.md](README.md).

## Що вона робить сама

Після виклику навички в Claude Code діють три локальні перевірки (хуки): склад має давати 100 %, «бамбук» записується як «віскоза», щільність відповідає типу тканини, закупівельні ціни й назви постачальників не потрапляють у публічний текст, прайс перевіряється на мінусові ціни та зайві нулі, а юридичні твердження й розрахунки не лишаються без дати та припущень. Налаштування й виняткові випадки — у [references/hooks.md](references/hooks.md) (російською). Вимкнути: `claude plugin disable textile-expert`.

Реєстрація хуків відповідає документації Claude Code, але автор не спостерігав її у живій сесії; для цього в `references/hooks.md` є перевірка на одну хвилину.

## Застереження

Це робоча довідка, а **не юридична, митна чи податкова консультація**. Правила маркування, повернення, мита, ПДВ і походження змінюються; правові примітки датовані й посилаються на джерела. Усе важливе перевіряйте у юриста, митного брокера чи бухгалтера та за первинними джерелами (zakon.rada.gov.ua, customs.gov.ua, dpss.gov.ua). Ці примітки юрист не перевіряв.
