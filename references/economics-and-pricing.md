# Экономика текстильного бизнеса: себестоимость, цена, закупка, склад

Читать при: расчёте цены, оценке выгодности поставщика, планировании закупки, споре «а выгодно ли это». Для расчёта запускайте `scripts/landed_cost.py` — не считайте в уме и не «прикидывайте» (хук Stop требует показывать допущения).

## 1. Полная себестоимость (landed cost) — формула

```
таможенная стоимость (грн) = (цена товара + доставка/страховка до границы Украины) × курс
пошлина                    = таможенная стоимость × ставка (по УКТЗЕД и происхождению)
ввозной НДС                = (таможенная стоимость + пошлина) × 20 %
                             → расход для НЕплательщика НДС; налоговый кредит для плательщика
собственные расходы        = брокер + доставка по Украине + банк/конвертация + контроль качества/лаборатория
повна собівартість         = таможенная стоимость + пошлина + (ввозной НДС, если не плательщик) + собственные расходы
продаваемое количество     = закупленное × (1 − потери %)       # усадка, брак, «хвосты» рулонов, образцы
собівартість 1 од.         = повна собівартість / продаваемое количество
```

**Три ошибки, из-за которых магазины «продают в ноль»:**
1. Берут цену поставщика × курс и забывают про логистику, НДС, брокера, банк и потери.
2. Считают наценку вместо маржи: наценка 50 % = маржа 33 %. Цена = себестоимость / (1 − маржа).
3. Не закладывают потери: рулон 50 м даёт 47–48 м пригодных (концы, дефекты), усадка ткани ещё забирает 3–5 %; для штор — припуск на подгибы.

**Курс.** Для таможенной стоимости — официальный курс НБУ на дату декларации; для оплаты поставщику — курс банка/торговый (с комиссией). Закладывайте запас на колебание: 2–5 % для закупок, оплачиваемых за 1–2 месяца до продажи.

### Иллюстративный пример (числа выдуманные, не прайс)
Сатин-хлопок, 5 000 м по 2,8 USD, доставка до границы 650 USD, курс 41,5, пошлина 10 % (условно), брокер 9 000 грн, доставка по Украине 6 500 грн, банк 1 %, потери 3 %:

| | Не плательщик НДС | Плательщик НДС |
|---|---|---|
| Повна собівартість | 823 837 грн | 690 083 грн |
| Собівартість 1 м (из 4 850 м) | 169,86 грн | 142,29 грн |
| Цена без НДС при марже 35 % | 261,33 грн | 218,90 грн |
| Роздрібна цена для покупателя | 261,33 грн | 262,68 грн (с НДС 20 %) |

Вывод: статус по НДС меняет *структуру* цены, а не обязательно итог для покупателя; но для неплательщика ввозной НДС — реальный расход, и без него расчёт занижен на 15–20 %. Ставка пошлины и сценарий НДС — допущения, подтверждаются у брокера/бухгалтера.

## 2. Ценообразование

- **Маржа и категории (ориентиры, не нормативы):** база (бязь, махра) — 25–40 %; сезон/подарок (сатин, жакард, пледы) — 35–55 %; премиум/эксклюзив (лён, шёлк, итальянские позиции) — 45–65 %. Реальные цифры берите по своей структуре расходов: реклама, маркетплейсы (комиссии 8–20 %), возвраты, упаковка, ФОТ.
- **Пороговые цены:** 499 / 999 / 1 499 грн — психологические. Комплекты и «набор для спальни» увеличивают средний чек; подарочная упаковка — отдельная позиция с маржой выше средней.
- **Скидки:** «старая цена» должна быть реальной (товар продавался). Скидка ≥ 50 % от «старой» — хук price_guard просит подтверждение.
- **Оптовая и дропшиппинг-цена:** считайте от себестоимости + минимальная маржа 12–20 %; фиксируйте MOQ и условия возврата.
- **Маркетплейсы:** цена должна покрывать комиссию + логистику + возвраты + рекламу; для категорий с высоким процентом возвратов (цвет/размер) закладывайте +3–6 % к стоимости.

**Чек перед публикацией цены:** (1) Маржа ≥ порога (`min_gross_margin_pct`, по умолчанию 20 %), (2) цена не ниже себестоимости, (3) нет «лишнего нуля» по сравнению с соседними позициями, (4) цена в карточке и в фиде совпадают, (5) если есть «старая цена» — она реальна.

## 3. Закупка: минимальная партия, сезонность, оборачиваемость

- **MOQ:** рулон (30–100 м) / паллет / фабричная упаковка (комплекты по 4–6 шт). Минимальные расходы на логистику «съедают» маленькие партии; для теста берите образцы + 1–2 коробки, масштабируйте по результатам.
- **Сезонность (ориентир по рынку Украины, проверяйте по своим данным):**
  - постельное бельё и полотенца — пик в канун Нового года и 8 марта, а также август–сентябрь («новая квартира», студенты);
  - пледы/фланель — с сентября по декабрь;
  - шторы — весна (ремонты) и конец лета;
  - льняное бельё и лёгкий поплін — апрель–июль.
- **ABC/XYZ.** A — 20 % артикулов дают ~80 % выручки (держать в наличии всегда); X — стабильный спрос (автоматический дозаказ), Z — сезонный/прерывистый (заказывать на сезон, ограниченный тираж как аргумент).
- **Точка дозаказа:** (средний дневной спрос × срок поставки в днях) + страховой запас (обычно 20–30 % от срока поставки по сложным поставщикам). Для Китая срок поставки 35–60 дней → запас больше; для Турции — 10–20 дней; для Германии со склада — 7–20 дней, под заказ — дольше; для Португалии под производство — 5–9 недель (4–8 недель производство + ~1 неделя доставка), со стока — 2–3 недели.
- **Цвета/принты:** меньше SKU — больше оборот; лишние цвета в линейке сильно повышают остатки. Цвет, который не продался за сезон, уходит в распродажу (учтите это в марже линейки).
- **Рулоны и лоты:** весь заказ одного цвета — из одного лота крашения; докупка спустя месяцы даёт разнотон (проверяйте образец).

## 4. Рабочий капитал и валютный риск

- Считайте цикл: оплата поставщику → производство → логистика → склад → продажа → деньги. Для Китая 90–150 дней, для Турции 40–80, для Португалии под заказ 60–100, для немецкого складского товара 20–50 — это сколько денег «заморожено».
- Хеджирование — планируйте закупки в валюте поставщика и держите частичный запас валюты, либо привяжите прайс к курсу с порогом пересчёта (напр., пересчёт цены при изменении курса > 3 %).
- Предоплата новому поставщику — риск: делите платёж на 2–3 части, оплату остатка делайте после подтверждения качества по образцам/инспекции.

## 5. Показатели, которые нужно знать

- **Валовая маржа** = (выручка без НДС − себестоимость) / выручка без НДС.
- **GMROI** = валовая прибыль / средний запас по себестоимости (в годовом выражении; текстиль хорошо — выше 2–3).
- **Оборачиваемость запасов** (дни) = средний запас / себестоимость продаж за день.
- **Доля возвратов, %** по причине (цвет, размер, качество) — важнее общей цифры.
- **Конверсия карточки, средний чек, стоимость привлечения (CAC)** — рекламный бюджет должен окупаться из валовой прибыли, а не из выручки.

## 6. Логистика и риски в пути

- Груз страхуется на 110 % стоимости; ткани боятся влаги — требуйте упаковку в плёнку, поддоны, при морских перевозках — контейнер с влагопоглотителями.
- Проверяйте условия поставки (Incoterms): FOB/FCA/EXW/CIF/DAP — кто платит и отвечает на каждом отрезке. Стоимость доставки до границы входит в таможенную стоимость.
- Документы для брокера: инвойс, пакинг-лист, контракт, транспортный документ, сертификат происхождения (если используете льготный режим), сертификаты/протоколы по требованию.
- Товары из ЕС (Германия, Португалия, Италия): счёт без местного НДС только при экспортном оформлении; пошлина по ЗСТ — 0 только при подтверждении происхождения ЕС (декларация на инвойсе/EUR.1). Если документа нет или товар фактически азиатского происхождения — в `landed_cost.py` ставьте полную ставку пошлины и сравните оба сценария.
- Внутри Украины: перевозчики (Нова пошта, Укрпошта, транспортные компании); для рулонов — спецупаковка, учитывать габариты и вес (метры → килограммы: г/м² × длина × ширина).

## 7. Если расчёт «слишком хорош»

Пересчитайте с худшими допущениями: курс +5 %, потери +3 п.п., логистика +20 %, пошлина по более высокой ставке. Если результат всё ещё приемлем — берите. Если нет — просите поставщика пересмотреть условия или ищите альтернативу.
