# Контроль качества: стандарты, сертификаты, приёмка, рекламации

Читать при: приёмке партии, составлении ТЗ/спецификации для поставщика, проверке сертификатов, разборе претензии покупателя, выборе лаборатории. Номера стандартов даны для ориентира при заказе испытаний — уточняйте актуальную редакцию у лаборатории.

## 1. Что проверять и по какому методу

| Параметр | Метод (ориентир) | Практический порог (типичные требования, согласуйте с поставщиком) |
|---|---|---|
| Масса на единицу площади (г/м²) | ISO 3801 (быстро — вырезка 10×10 см) | допуск ±5 % от заявленной |
| Состав волокон | ISO 1833 (количественный анализ смесей), лаборатория | допуск между заявленным и фактическим ≈ 3 % по абсолютной величине |
| Усадка при стирке | ISO 6330 (режимы стирки/сушки) + ISO 5077 (измерение) | хлопковая ткань ±3 %, трикотаж ±5 %; перекос ≤ 5 % |
| Цветостойкость к стирке | ISO 105-C06 | окраска/перекрашивание — не ниже 4 (шкала 1–5) |
| Цветостойкость к трению | ISO 105-X12 | сухое ≥ 4, мокрое ≥ 3 |
| Цветостойкость к поту | ISO 105-E04 | ≥ 3–4 |
| Цветостойкость к свету | ISO 105-B02 | штора/гостиная ≥ 5 (шкала 1–8), постель обычно ≥ 4 |
| Пиллинг | ISO 12945-2 (Мартиндейл) | ≥ 3–4 |
| Истираемость | ISO 12947-2 (Мартиндейл) | для обивки/штор — по назначению (десятки тысяч циклов) |
| Прочность на разрыв | ISO 13934-1 (полоса) | по назначению ткани |
| Раздирание | ISO 13937 | по назначению |
| Скольжение нитей в швах | ISO 13936 | критично для сатина и плотных тканей |
| pH водной вытяжки | ISO 3071 | ≈ 4,0–7,5 для детских, 4,0–9,0 для остальных изделий (ориентир OEKO-TEX) |
| Формальдегид | ISO 14184 | OEKO-TEX I (детские): ≤ 16 мг/кг (не обнаруживается); II: ≤ 75 мг/кг |
| Амины из азокрасителей | EN 14362 | не обнаруживаются (< 30 мг/кг) |
| Огнестойкость (шторы для общественных помещений) | EN 13501 / национальные нормы | по требованиям объекта |

*Цифры в правом столбце — типичные коммерческие требования и пороги стандартов качества; они не заменяют требования законодательства и конкретного заказчика.*

## 2. Сертификаты и маркировка — что они значат на самом деле

- **OEKO-TEX® STANDARD 100** — проверка на вредные вещества в готовом изделии; классы: I (младенцы до 3 лет), II (прямой контакт с кожей), III (без прямого контакта), IV (мебель/обивка). Сертификат выдан *конкретной компании на конкретные позиции*, срок — 1 год. Проверка — в базе OEKO-TEX (Label Check) по номеру и названию компании. «OEKO-TEX» ≠ «органик».
- **GOTS** — органический текстиль по всей цепочке: «organic» ≥ 95 % органических волокон, «made with organic» ≥ 70 %; подтверждается сертификатом цепочки и номером лицензии, проверяется в базе GOTS.
- **OCS (Organic Content Standard)** — только доля органического сырья (5–100 %), без требований к красителям/химии.
- **BCI (Better Cotton)** — программа, поддерживающая более устойчивое выращивание хлопка по принципу «mass balance»; *не* означает, что в вашей ткани физически BCI-хлопок, и это *не* органика.
- **GRS/RCS** — переработанное сырьё. **STeP, Made in Green** — отдельные программы OEKO-TEX (условия производства / прослеживаемость).
- **Tencel™/Lenzing** — торговая марка волокон ліоцел/модал; подлинность подтверждается лицензией и маркировкой.
- **Протоколы испытаний (SGS, TÜV, Intertek, BV, Hohenstein (Германия), CITEVE (Португалия) и др.)** — смотрите дату, номер образца, соответствие образца вашей позиции, перечень методов.
- **Пух и перо (одеяла, подушки — частый немецкий ассортимент):** состав наполнителя маркируется по EN 12934 (доля пуха и пера, например «90 % пух / 10 % перо»); происхождение и благополучие птицы подтверждают Downpass или RDS (Responsible Down Standard); знак NOMITE — пригодность для людей с аллергией на клеща домашней пыли (заявление о «гипоаллергенности» всё равно только с документом). Проверяйте класс и номер сертификата так же, как OEKO-TEX.

**Красные флаги:** логотип без номера; сертификат на другую компанию/другой продукт; истёкший срок; «сертифицировано» без документа; просроченный/сканированный «из интернета» протокол.

## 3. Приёмка партии в Украине (внутренний регламент)

**Перед отгрузкой (желательно)**
1. Утвердить *golden sample* (эталон) и ТЗ: состав, г/м², ширина, допуски, цветостойкость, усадка, упаковка, маркировка.
2. Инспекция третьей стороны на 80 % готовности партии для крупных заказов (AQL по ISO 2859-1; для бытового текстиля часто 2,5 для критичных/значительных и 4,0 для незначительных дефектов, уровень контроля II — согласуйте).
3. Один номер партии крашения (lot) на заказ; рулоны/комплекты с разными лотами не смешивать в одной позиции.

**После прихода на склад**
1. Целостность упаковки, влага/плесень, запах химии.
2. Сверка с инвойсом и пакинг-листом: количество мест, метры/штуки.
3. Выборочная проверка (корень из числа мест + контрольные позиции): ширина рулоном/рулеткой, вес образца 10×10 см, цвет к эталону при дневном свете, ярлык и состав.
4. *Четырёхбалльная система* для рулонов (ASTM D5430-подход): штрафные баллы за дефекты на 100 кв. ярдов; партия обычно допускается при ≤ 40 баллов/100 кв. ярдов (для ответственных заказов — 20). Дефекты более 9 дюймов — 4 балла, 6–9 — 3, 3–6 — 2, до 3 — 1.
5. Тест стирки образца (40 °C по ярлыку): размеры до/после, цвет белого свидетеля, пиллинг, запах.
6. Решение по партии: принять / принять со скидкой / вернуть. Акт фиксируется в течение сроков договора (фото, видео, акты).

## 4. Быстрые тесты без лаборатории

- **Горение** (осторожно, над раковиной, небольшой лоскут): хлопок/лён — горят быстро, запах бумаги, серый пепел; шёлк/шерсть — запах палёных волос, гаснет сам, хрупкий чёрный шарик; полиэстер/полиамид — плавится, шарик, химический запах; вискоза — горит как хлопок, мало пепла. Только для ориентира; для состава нужна лаборатория.
- **Трение**: белой влажной салфеткой/тканью потереть окрашенный участок 10 раз — остаётся ли цвет.
- **Усадка**: 3 образца 50×50 см, обвести маркером, постирать по ярлыку, высушить, измерить.
- **Цветостойкость**: белый свидетель + образец в тёплой воде на 30 минут.
- **Запах**: сильный резкий запах — повод для лабораторного теста формальдегида.
- **Свет**: окно + лампа: просвет и однородность ткани; для блэкаута — тест на лист бумаги/фонарь.

## 5. Разбор претензии покупателя

1. Собрать: номер заказа, фото/видео дефекта и ярлыка, режим стирки, дату получения.
2. Классифицировать: *производственный дефект* (швы, пятна, нарушение размеров, цветостойкость в пределах эксплуатации) / *нарушение ухода* / *ожидание не совпало с карточкой* (цвет на экране, размер, плотность).
3. Решение: замена, возврат, скидка — согласно политике магазина и закону (см. `ukraine-legal.md`).
4. Фиксировать в журнале: ткань/партия/поставщик/причина — повторяющийся дефект = основание для рекламации поставщику и корректировки ТЗ.
5. Если причина — карточка (цвет, размер, плотность), исправить карточку, а не только возместить покупателю.

## 6. Рекламация поставщику

Подавать письменно в срок, указанный в договоре; приложить акт приёмки (фото/видео, замеры, результаты испытаний). Предлагать конкретный вариант: замена, скидка, возврат. Для сертификатов/протоколов — требовать исправленные документы. Эскалация: независимая экспертиза (лаборатория), страховка, арбитраж по договору.
